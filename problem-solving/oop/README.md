# 🐍 Python OOP Practice

A collection of Python OOP exercises designed to build a practical understanding of **Object-Oriented Programming** through progressively more challenging problems.

The exercises cover fundamental OOP concepts such as classes, objects, instance attributes, methods, validation, inheritance, method overriding, polymorphism, and composition.

## 📚 Exercises

### 1. 🟢 Student Profile

A simple `Student` class representing a student's basic information.

The exercise focuses on creating objects, defining instance attributes, and implementing an instance method to display student information.

**Concepts practiced:**

* Classes & Objects
* Constructors (`__init__`)
* Instance Attributes
* Instance Methods
* Object State Modification
* `return` vs `print`

---

### 2. 🟡 Bank Account

A simple bank account system that manages an account owner's balance.

The system supports depositing and withdrawing money while performing basic validation to prevent negative amounts, insufficient funds, and invalid initial balances.

**Concepts practiced:**

* Classes & Objects
* Constructors (`__init__`)
* Instance Attributes
* Instance Methods
* Basic Validation
* Conditional Logic
* Exception Handling

---

### 3. 🟠 Library System

A small library management system built using two interacting classes: `Book` and `Library`.

The `Library` maintains a collection of `Book` objects and allows books to be added, borrowed, returned, and displayed based on their current availability.

**Concepts practiced:**

* Multiple Classes
* Classes & Objects
* Instance Attributes
* Instance Methods
* Object Interaction
* Collections of Objects
* Object State Management
* Basic Validation

---

### 4. 🔴 Employee Management System

A simple employee management system using a base `Employee` class and specialized `Developer` and `Manager` classes.

The system demonstrates how specialized classes can inherit common functionality from a parent class while providing their own role-specific behavior.

**Concepts practiced:**

* Classes & Objects
* Inheritance
* `super()`
* Method Overriding
* Polymorphism
* Instance Attributes
* Instance Methods

---

### 5. ☠️ E-Commerce Shopping Cart

A small e-commerce shopping cart system consisting of `Product`, `ShoppingCart`, and `Customer` classes.

The system manages products, quantities, stock, cart operations, total calculations, and checkout functionality. It also demonstrates how objects can be composed together to model relationships between customers, shopping carts, and products.

**Concepts practiced:**

* Multiple Classes
* Classes & Objects
* Composition
* Object Interaction
* Dictionaries with Objects
* State Management
* Basic Validation
* Exception Handling
* Working with Collections of Objects

---
